# FineWood-Furnitures-and-AGlobia-Furnitures-HR-App

Cross-platform HR management mobile app built with React Native CLI for FineWood & AGlobia Furniture. Features include role-based authentication, attendance tracking, leave management, inquiry handling, secure API integration, real-time updates, responsive UI, file handling, and exportable HR reports.

- Developed a cross-platform HR management mobile app for Finewood and AGlobia Furniture using React Native CLI. Implemented user authentication and role-based access (Admin, Staff, HR) with token-based login and secure API calls.
- Built core HR features including attendance tracking, leave requests, inquiry management, and profile management. Integrated React Native libraries like react-navigation, axios, react-native-fs, react-native document-picker and react-native-vector-icon for smooth navigation, data handling, and enhanced UI/UX.
- Designed clean, responsive UI with custom animations for a modern and intuitive experience. Implemented real-time API communication for live updates and optimized performance. Delivered an exportable data and report feature for HR analysis and decision-making.

## Getting Started

This project was bootstrapped with React Native.

### 1. Install dependencies

```sh
npm install
```

### 2. Start Metro

```sh
npm start
```

### 3. Run the app

#### Android

```sh
npm run android
```

#### iOS

```sh
npm run ios
```

> Note: Make sure you have completed the React Native environment setup guide before running the app.
